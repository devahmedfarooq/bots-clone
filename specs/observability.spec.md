# Observability

Run pins bot version + base model + adapter (empty for baseline) -> trace resolved settings -> tool_started saved before effect -> tool_finished duration/result -> terminal status/reason/duration/usage.
Crash between tool_started and tool_finished -> uncertain side effect, never automatic replay.
Service job completion -> resource snapshot using existing diagnostics -> system used RAM and aggregate device VRAM, NOT per-run allocation or peak -> persisted job view.
Persist and HTTP encode through recursive pattern redaction; trace records never contain external environment credentials.
